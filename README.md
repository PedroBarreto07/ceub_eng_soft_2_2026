# Indústria4.0

Loja fictícia de automação industrial, criada como projeto da disciplina de Desenvolvimento Web do curso de Ciência da Computação — UniCEUB.

## Sobre o projeto

O site simula uma loja online de equipamentos de automação (sensores, CLPs, gateways IoT, painéis HMI), com catálogo de produtos, preços e um carrinho de compras funcional feito em JavaScript.

## Como visualizar

Basta abrir o arquivo `industria4.0.html` no navegador — não precisa de servidor ou instalação.

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
